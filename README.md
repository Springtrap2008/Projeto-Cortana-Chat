# Cortana Chat - Lore de Halo

Chatbot inspirado na Cortana de Halo 4, com foco na lore do universo de Halo.

## Características

- 333 artigos sobre Halo
- Rampancy em tempo real (7 anos)
- Fase Created (Halo 5)
- Sem LLM — funciona com regras e wiki local
- 100% em português brasileiro

## Como usar localmente

Duplo clique em `iniciar.bat` e acesse http://localhost:5000

## Tecnologias

- Python + Flask (backend)
- HTML + CSS + JavaScript (frontend)
- Hugging Face Spaces (hospedagem)
